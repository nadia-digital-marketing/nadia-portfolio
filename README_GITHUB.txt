Nadia Digital Marketing Website - GitHub Pages

Files:
- index.html: Complete website page. The logo and current image assets are embedded in the HTML file.

Upload instructions:
1. Extract this ZIP on your computer.
2. Open your GitHub repository: nadia-digital-marketing/nadia-portfolio
3. Choose Add file > Upload files.
4. Upload index.html (not the ZIP file itself).
5. Click Commit changes.
6. Open Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.

Note: The website's video/design picker previews files locally in the browser. It does not upload selected videos or designs for public visitors. Public media needs to be hosted and linked separately.
